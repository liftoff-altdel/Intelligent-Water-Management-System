# Intelligent Water Management System

## About the Project

This project is an ESP32-based intelligent water management system developed to automate water level control while monitoring water quality and detecting water leakage.

The system combines PID-based water level control with real-time sensing to improve water usage efficiency and ensure safe drinking water.

---

## Features

- PID-based water level control
- Real-time leakage detection
- Water flow monitoring
- Turbidity monitoring
- TDS monitoring
- ESP32-based embedded system
- Local alerts using buzzer
- Designed for future IoT integration

---

## Components Used

- ESP32 Development Board
- Ultrasonic Sensor
- Water Flow Sensor
- Turbidity Sensor
- TDS Sensor
- L298N Motor Driver
- DC Water Pump
- Buzzer
- Jumper Wires
- Breadboard

---

## Working Principle

The ultrasonic sensor continuously measures the water level in the source tank. The ESP32 uses a PID controller to regulate the water pump and maintain the desired level.

Water flow is monitored to detect possible leakage, while turbidity and TDS sensors evaluate water quality before supplying water to the receiver tank.
